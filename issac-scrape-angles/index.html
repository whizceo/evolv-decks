What changes about the money

The sheet priced five angles as paid work. Four of them turned out to have a free path that had simply not been looked for, and one of them is genuinely worth buying.

Officer and owner-name match — the sheet says a Secretary of State quote is needed. It was built twice for nothing, from two separate government files. No quote is needed.

UCC-1 maturity map — priced at roughly one to five dollars per name, which makes it unbuildable across a 261,000-row registry. A free federal file replaces it and carries more: the loan amount and the origination date, neither of which a UCC-1 gives you.

Careers pulse and website time-travel — both budgeted for Apify. Plain HTTP and the keyless Wayback API do the work, and staying off the search engines makes them immune to the blocks that killed press mining.

Owner's last review reply — this one really does cost money. Google Maps has no free API and blocked direct access. It is the highest-scored angle on the sheet, and the sheet's price was right.

Two things found that were not on the sheet

261,313 registry rows audited against two independently published Comptroller files. 323 businesses are confirmed closed and still sitting in the list — 174 of them the registry still marks as active. Closure is only ever asserted when a second file records a closure date; absence alone is written as unverifiable, because a service business can surrender a permit and trade on for decades.

104,299 outlet records across 1.45 million Texas sales-tax outlets. 1,293 businesses are quietly shutting locations while still trading. This is the only angle in the build that reads decline off a government file with a date on it instead of inferring it from silence, and its verdict arrives before the business is gone. Two traps are guarded: a chain closing 52 of 347 stores is a property team's decision rather than an owner's, and a surrendered permit followed by a new one within 180 days is a move, not a death.

The rule that shaped every file

A blocked request is not an empty result. Nothing in these files reports “nothing found” unless the source was actually reached and actually answered.

This matters more than it sounds. If a rate-limited search gets written down as “this company has no website”, that false negative is indistinguishable from a fact and nobody downstream can catch it. Six separate false signals were caught in this run's own output, and each was labelled rather than deleted — a deleted row is invisible, a labelled row can be checked.

The same rule caught the tool audit itself: the first pass reported five dead tools, and four of them were bugs in the probe, not dead tools.

Honest gaps — read before trusting a blank

Local press is dead as a source. Google News, Bing, Yahoo and GDELT were all tested. Zero press rows means nobody could be asked, not that there is no coverage.

Websites resolved for 55% of the 3,000 tested — 1,636 evidenced, plus 891 unverified candidates held back for review. 473 names were never searched at all because the free endpoint refused, and those are logged as not asked rather than as no website.

Three angles ran on the evidenced domains only. Their small row counts prove the code works; they are not a measure of how many businesses qualify.
